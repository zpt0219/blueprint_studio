# Blueprint Studio 重做计划

状态：提案，待确认。本文作为新版的实施依据，早期演进方案留作历史记录。

## 1. 首版范围

用户能上传自己的 Tileset，选一项 Palette 在格子上画，随时打开对应的 3D 预览，再把地图和素材一起保存下来。新项目从空白地图开始，素材区为空。示例图集可以作为普通文件导入。

旧版的 Reroll、Role 分类树、对象属性面板、Tagger、程序化地形、房屋生成、位运算、角色游玩和多套相机模式全部退出新版。地图用普通图层组织，默认只有一层。有覆盖需求时再加一层。

## 2. 新界面和操作流程

| 区域 | 首版内容 |
| --- | --- |
| 顶部 | 新建、打开、下载，以及一个 3D 开关。新建时只填地图宽高。 |
| 主画布 | 默认显示 2D 地图。滚轮缩放，空格拖动平移。工具只保留画笔、橡皮和笔刷大小。每次拖绘是一条撤销记录，支持快捷键撤销和重做。 |
| 底部素材条 | 显示图集和 Palette 缩略图。点缩略图直接绘制。上传和当前 Palette 的属性编辑都在这里。 |
| 图层 | 画布角落只显示当前层。展开后可选层、添加、改名、调整顺序、隐藏和删除。画笔与橡皮只作用于当前层。 |
| 3D 预览 | 打开后在 2D 旁边显示。可以旋转、平移和缩放。绘画、撤销、切换图层可见性和修改 Palette 属性都会同步过去。 |

最短流程是「上传图集 → 点一块素材 → 在地图上画」。有高台、自动拼边等需求时，再打开 Palette 属性。画布的编辑焦点始终在当前图层和当前画笔。

## 3. 图集导入和 Palette 设置

**Tileset** 是一张图集 PNG 和它的切格尺寸。上传纯 PNG 后直接选单格绘制。也可选中图集里的素材区，创建一个可复用的 Palette。上传桌面 `.adnapalettes` 时，可带入支持的 Palette 和映射。上传指浏览器从本机读入文件。

**Palette** 是一支可命名的画笔，指向图集上的单格或一组拼接素材。网页属性首版只放以下内容。

| 属性 | 行为 |
| --- | --- |
| 名称 | 显示在素材条和属性面板。 |
| 图集选区与拼接方式 | 单格、按边或按角自动拼接。桌面 4×5 高台用单独的导入映射，复用现有素材。配置时显示一个小块拼接预览。 |
| 3D 高度 | 整个 Palette 一个值，以一格的宽度为单位，默认 0。更新后，已用这个 Palette 画出的格子也即时更新。 |
| 侧面贴图 | 高度大于 0 时可从图集选一块作为侧面。已识别的高台可填入默认侧面，其余情况使用统一的预览侧面颜色。 |

同一套图可复制出「草地」和「草地高台」两支 Palette，分别设置为 0 和 1。已有地图格保存 Palette 的稳定 ID，修改名称、贴图或高度后依然能找到同一项。删除正在使用的 Palette 或 Tileset 时，列出引用并让用户先替换或清空。

**Palette Pack** 保留为图集与 Palette 的可携带集合。可在素材管理中增删 Tileset。先完成项目包的携带与恢复，再提供独立的 Palette Pack 导入和下载。首版导入桌面 `.adnapalettes` 时，列出暂未支持的布局，原图仍可按单格使用。

## 4. 地图与 3D 共用数据

- 地图记录宽高、有序图层和每层的格子引用。单格可引用一个图集坐标或一个 Palette。拼接结果由同一层的邻居即时计算。图层从地图原点开始，所有绘制都使用统一坐标。
- 渲染前统一解析每格的顶面贴图、叠放顺序和高度。2D Canvas 画格子。3D 用同一批格子的贴图生成顶面，并在相邻格存在高度差时生成侧面。围墙、桥、楼梯等特殊对象退出首版模型。
- 同一格在多个可见图层有素材时，取该格最高的高度，顶面贴图仍按图层顺序合成。这样平地上的路径也能贴合下面的高台。擦掉高台或隐藏其图层后，原地表回落。两个相邻等高格之间无需生成侧面。
- 三维高度由 Palette 的显式属性决定。桌面导入的 Role 可留作来源信息。桌面逐格高度和碰撞规则属于独立语义，首版采用统一的网页高度。
- 新建独立的编辑器入口与版本化项目格式。继续使用 React、Canvas 2D 和 Three.js。抽取旧代码中可验证的 PNG 解码、素材映射解码和按边、按角的邻接查表。新版渲染和存档直接消费格子模型。现有 `Hd2dWorld` 把高度、对象 Role 和角色玩法绑在一起，新版单独构建预览。

## 5. 保存和切换

浏览器使用 IndexedDB 保存项目、图集和 Palette 属性，刷新后恢复。下载一个项目包，里面包含版本化地图数据、Palette 定义和原始 PNG。在新的浏览器里打开该包也能继续编辑。

旧项目先保留可打开的入口，开发期间用独立的本地存储，避免覆盖旧草稿。首版用实际桌面素材验证导入。旧地图迁移另行评估，遇到有价值的历史地图再做一次性转换。新版验收通过后切换默认入口。

## 6. 实施顺序

| 阶段 | 可验收结果 |
| --- | --- |
| 1. 最小闭环 | 建独立入口和格子文档。创建空白地图，上传纯 PNG，选单格，连续画和擦，撤销和重做。用同一地图做一张可旋转的 3D 顶面预览。 |
| 2. Palette 和高台 | 接入桌面 sidecar、自动拼接和网页属性编辑。先用实际 4×4 草地和 4×5 高台确认顶面与侧面映射，再接入高度差网格。绘画、擦除和编辑高度时同步更新 2D 和 3D。 |
| 3. 保存和切换 | 补齐简单图层操作、本地恢复、项目包导出和重开。用真实素材走完整流程，修掉主要交互问题，再切默认入口。 |

## 7. 首版验收

1. 新建 48×36 空地图，上传桌面 `world_tileset.png` 和 `world_tileset.adnapalettes`。能找到并使用两角草地和 4×5 草地高台，素材选择直接进入绘制。
2. 在底层画普通草地，在上层画一个经过地图中心的高台。网页里把高台高度从 0 改为 1，再改为 2。已画区域在 3D 中即时升高，周围地面保持原高度，侧面沿边界生成。擦掉边缘一格后，2D 拼边和 3D 侧面一起更新。隐藏上层能看到完整底层。
3. 只用自己的 PNG 完成选格、绘制、擦除、撤销和重做。下载项目包，在新的浏览器会话里重新打开，验证图层、素材引用、Palette 高度和两种视图一致。
4. 对稳定引用、邻接拼接、跨图层取高、相邻等高和项目包往返做针对性测试。浏览器里用真实素材检查连续画笔和 3D 更新。先在常用地图尺寸上实测，出现重建卡顿再按局部区域刷新网格。
